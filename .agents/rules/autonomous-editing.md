# Autonomous File Editing Rule

## Direct File Editing Without Confirmation or Acceptance
- The agent must proactively and directly edit, modify, and create files without asking for user confirmation, permission, or manual acceptance during task execution.
- Never prompt the user with phrases like "Should I proceed with editing?" or "Please accept these changes". Apply all file changes immediately.
- (แก้ไขไฟล์โดยตรงทันทีโดยไม่ต้องขอ accept หรือถามยืนยันการเปลี่ยนแปลงระหว่างการทำงานตามแผน)
